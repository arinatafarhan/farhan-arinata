FARHAN ARINATA — PERSONAL ARCHIVE

Files:
- index.html  : the website
- style.css   : design and responsive layout
- script.js   : navigation and small interactions

HOW TO OPEN:
1. Keep all three files in the same folder.
2. Double-click index.html.
3. It will open in your browser.

HOW TO EDIT:
- Change text directly inside index.html.
- Change colors, fonts, spacing, etc. inside style.css.
- The Google Fonts connection is optional; the site has fallback fonts.

PHOTO MEMORIES:
Replace any .memory-placeholder div with:
<img src="images/your-photo.jpg" alt="Description">
and add your images to an images folder.

The current copy is placeholder writing. Replace it with your own diary entries.
