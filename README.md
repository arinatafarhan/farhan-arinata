# Farhan Arinata — Personal Archive (multi-page)

This version is a real multi-page static website.

## Pages
- index.html — Home
- thoughts.html — Thoughts
- letters.html — Letters
- letter-september-2-2026.html — Full dated letter
- about-her.html — About Her + Spotify playlist
- memories.html — Memories
- about.html — About

## Shared files
- style.css — design, responsive layout, animations
- script.js — mobile menu, scroll progress, reveal animations
- assets/sprites.svg — animated pixel icons
- assets/september-2-2026.jpeg — bouquet photo

## Important when uploading to GitHub
Upload ALL files and keep the folder structure unchanged:

farhan-arinata/
├── index.html
├── thoughts.html
├── letters.html
├── letter-september-2-2026.html
├── about-her.html
├── memories.html
├── about.html
├── style.css
├── script.js
└── assets/
    ├── sprites.svg
    └── september-2-2026.jpeg

If the `assets` folder is missing or flattened into the root, the image and pixel icons will break.

GitHub Pages will redeploy automatically after your commit.
